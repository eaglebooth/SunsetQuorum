# SunsetQuorum logo-derived design system

Source: user-supplied square logo, reviewed 2026-09-24.

- Palette: ivory `#fff9f2`, paper `#f7eee5`, amber `#ffb52e`, orange `#ff6b22`, signal red `#f12d25`, aubergine `#2c2031`, muted plum `#6c5a6b`.
- Geometry: oversized semicircle/sunset, horizontal cut lines, heavy rounded server blocks, circular prohibition mark.
- Mood: warm operational sunset rather than cyberpunk; decisive, calm, infrastructural.
- Logo treatment: preserve full square and internal ivory margin; use `object-fit: cover` only inside a matching ivory rounded frame so the source's white perimeter disappears visually.
- Typography: high-contrast editorial display plus narrow technical mono labels.
- UI motifs: horizon rules, quorum lanes, segmented readiness bars, sunset gradient only for consequential action/status.
- Avoid: purple gradients, glass cards, generic SaaS sidebar, tiny logo in a bordered white box.
